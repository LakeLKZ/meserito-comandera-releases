# MeseritOS · Comanderas — instaladores

Este repositorio solo contiene los **instaladores firmados** de la app de comanderas de MeseritOS
(la que imprime las comandas en las impresoras del local). No hay código ni datos de clientes.

- Cada versión se firma digitalmente (Ed25519). La app **solo instala actualizaciones con una firma válida**:
  nadie que no tenga la clave del autor puede publicar una versión que las computadoras acepten.
- Para instalarla: bajá `MeseritOS-Comandera.exe` de la última versión (Releases) o desde el panel de MeseritOS.
- Después de la primera instalación se actualiza sola.

Ayuda: contacto@meseritos.com.ar
